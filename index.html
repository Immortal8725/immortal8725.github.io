DigiMed Connect

Live paperless healthcare platform

The problem

Clinics still run on paper files and phone bookings. DigiMed Connect connects patients, doctors, clinics and staff on one platform.

What I built

  • RESTful APIs with a clean layered architecture (Controller → Service → Repository) in Spring Boot and PostgreSQL.
  • Patient management, appointment booking and multi-tenant clinic features on the React front end.
  • Real-time features with Node.js and Socket.IO.
